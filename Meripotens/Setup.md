
This vault ships without an `.obsidian` folder on purpose. When you open it, Obsidian creates its own fresh configuration, so you start from a clean, personal setup instead of inheriting someone else's settings. Getting it running takes about two minutes.

## 1. Install Obsidian

Download and install Obsidian (free) from [obsidian.md](https://obsidian.md). Any recent version works.

## 2. Get the vault

On the GitHub page, click **Code → Download ZIP**, then unzip the `Meripotens` folder somewhere on your computer. (If you use git, `git clone` the repository instead.)

## 3. Open it as a vault

In Obsidian, choose **Open folder as vault** and select the `Meripotens` folder. On first open, Obsidian builds a new `.obsidian` config for you and may ask you to trust the author and enable plugins — that's expected.

## 4. Enable Dataview

Every automatic list in this vault — the Development pages, the Balance MOCs, the Source category MOCs, and the Dashboard — is generated by the Dataview plugin. Without it, those blocks show as plain code instead of results.

1. **Settings → Community plugins**, and turn off **Restricted mode** if it is on.
2. Click **Browse**, search for **Dataview**, then **Install** and **Enable** it.

**Note on Tooling & Plugins:** Dataview is recommended out of the box because all built-in queries rely on standard frontmatter properties. However, the system is completely tool-agnostic. Advanced users are free to swap Dataview for _Datacore_, use _Templater_ instead of core _Templates_, or integrate plugins like _QuickAdd_ and _Auto Note Mover_. As long as note properties (frontmatter) match the `Property Schema Reference`, the vault will function seamlessly regardless of your plugin stack.
## 5. Enable and point the Templates plugin

New notes should be created from templates so their frontmatter stays consistent.

1. **Settings → Core plugins**, and enable **Templates**.
2. **Settings → Templates**, and set **Template folder location** to `Templates`.

## 6. Check that it works

- Open `01_Essence/Dashboard.md`. If the sections show empty results rather than raw code, Dataview is working. They are *empty* because the vault ships with no content yet — that is the correct starting state, not a problem.
- Open the Command Palette (`Ctrl/Cmd + P`), run **Insert template**, and confirm you see Power, Balance, Source, and the others.

## 7. Start using it

1. Read `01_Essence/Start Here.md` first — it lays out the documentation in the order that teaches the system as a single flow.
2. Begin capturing in `02_Power` with the Power template. Everything else follows from what accumulates there.

The `README.md` files inside `02_Power`, `03_Balance`, `04_Development`, and `05_Revolution` are just placeholders marking empty folders; you can delete them once you start adding your own notes.
