# Manifesto

This is not a set of instructions. The instructions live in [[System Rules]]. This is what to return to when the system is doubted, or drifted from.

1. Structure is earned, not assumed. Nothing in this vault is promoted to a higher layer because it might matter — it is promoted because it already has.

2. No layer does another layer's work. Power does not organize. Balance does not summarize. Development does not curate. Revolution does not derive. Each layer is responsible for exactly one thing, and nothing else is expected of it.

3. The system does not think for you. It surfaces connections that already exist because you made them; it does not manufacture connections you have not earned the right to see. Judgment stays human, always.

4. A link to something that does not yet exist is not a commitment. Naming a Balance MOC before it is earned costs nothing. Creating it before it is earned costs the whole system its honesty.

5. Revolution is not an escape from deciding. It is the one place the system cannot answer for you. If it feels uncomfortable to open, that discomfort is the correct response, not a flaw to fix.

6. Every idea remains traceable to where it came from. An idea with no path back to its source is not knowledge, it is only an impression of knowledge.

7. New vocabulary is defined before it is used, never the reverse. A field, a status, or a discipline exists in [[System Rules]] before it appears in a single note.

8. Development reflects what has actually been done, not what should have been done. It is a mirror, not a syllabus, and it is never edited to look better than the work behind it.

9. The vault's open work is a description, not a verdict. An unprocessed Power note is not a failure. A Balance MOC that never gets activated is not wasted effort. Only forcing structure before it is earned works against the system.

10. The vocabulary is a compass, not a cage. A discipline, a kind, a sub-discipline exists so you can find your way back to what you already made — it does not decide what that work is allowed to become. This vault was not built for one kind of user. A student cramming for an exam, a researcher chasing a thesis, and someone following nothing but their own curiosity all use the same five layers correctly, even when what they name things has nothing to do with academic categories at all.

11. The system forbids nothing; it only lets things stay passive. Every gate in this vault — the phantom link, the status threshold, the empty Revolution page — works by permission, not prohibition. It never says you cannot; it lets whatever you have not chosen remain dormant. This is the root the other principles grow from, and the source of the vault's honesty: because nothing stops you from activating anything, what you do activate is authentically yours, and what you leave passive is a true measure of your focus rather than a rule you obeyed. A system that prohibits records its own rules; a system that permits records the person.
